# PatchScope v0.9 repair-engine milestone

## Scope

This milestone changes only the opt-in SWE-bench development protocol. Legacy
manifests continue to use `exact_fragment_v1` and reproduce v0.8 behavior.

The v0.9 external manifest selects `line_range_hash_v1` and a distinct
experiment ID (`swebench_lite_dev_v09`).

## Changes

- Replaces globally unique `old` text with an inclusive observed line range.
- Computes the source SHA-256 inside PatchScope; the model cannot supply it.
- Rechecks that hash before materialization and application.
- Rejects ranges that were not completely displayed to the model.
- Renders proposal evidence with explicit line numbers.
- Runs an execution-free static gate for Python syntax and removed module-level
  bindings that remain referenced in the edited file.
- Preserves the old contract for historical manifests and frozen replay.

## Model output contract

```json
{
  "path": "package/module.py",
  "start_line": 120,
  "end_line": 122,
  "replacement": "replacement source with exact indentation\n"
}
```

The stored proposal additionally contains `expected_sha256`, derived from the
observed repository source.

Do not launch a new 23-instance model run until the full suite passes and the
source is frozen as a distinct v0.9 protocol snapshot.

unbiased benchmark. Report export rate, contract rejection categories, official

untouched holdout set.
